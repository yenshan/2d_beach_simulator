# SHORE 512

横512×縦256ピクセルの海の断面。左が砂浜、右が沖。画面はページ幅に合わせて整数ピクセルの輪郭を保って拡大します。

## 起動

```sh
npm install
npm run dev
```

ターミナルに出る Local URL を開きます。GPU版には WebGPU 対応ブラウザと `localhost` または HTTPS が必要です。初回はシェーダーのコンパイルを待ちます。WebGPUを利用できない場合、画面の「簡易表示で開く」から従来の手続き的な描画へ切り替えられます。GPU版が失敗しても自動的に物理演算を装うことはありません。

## 操作

波高・周期・風、4種のプリセット、一時停止、リセット、0.5/1/2倍速、512×256 PNG保存。波高のm表示は造波入力の目安で、観測値ではありません。最初の波が岸に届くまで数秒かかります。

## 構成

- `lib/fluid-shaders.ts`: 2DのMLS/APIC型粒子・格子流体。26,228粒子、320×128格子。二次補間、密度からの圧力、重力、海底衝突、画面外の右端ピストンによる造波。
- `lib/fluid-core.ts`: WebGPU computeの実行。1/480秒の固定刻み、フレーム遅延時の計算量上限、リセット、リソース破棄。
- `lib/gpu-ocean.ts`: Three.js WebGPURendererと同一のGPU device / StorageTextureを共有。通常描画ではGPU→CPUの読み戻しなし。512×256で粒子を水面へ合成。
- `lib/ocean.ts`: WebGPU非対応時にユーザーが選択できる旧簡易版。
- `app/page.tsx`: 操作と初期化・エラー・GPU切断の表示。

物理モデルは圧縮性を許す視覚表現用の近似です。泡は流体の密度と変形速度から生成する表示で、空気自体の流体計算はしません。巻き方は入力と海底によって変わり、毎回同じチューブ波になる保証はありません。

## 検証

```sh
npm run typecheck
npm test
npm run test:gpu
```

GPUテストはDawnを通じて実GPUで実行し、シェーダーの検証、粒子の有限性・海底衝突・波の岸への伝播・リセット・設定の両端、およびThree.jsへのテクスチャ共有と描画方向を確認します。GPUアクセスが制限された環境では許可が必要です。`webgpu`はテスト専用の開発依存でブラウザには配信しません。

Three.jsの内部バックエンドへの接続箇所は`gpu-ocean.ts`に集約し、バージョンを固定しています。更新時はGPUテストを実行してください。

格子間隔と粒子間隔を各方向に1/2にした高精細設定です。粒子数・格子セル数は従来の4倍、1粒子の質量は1/4とし、世界座標・重力・圧力・海底形状は維持しています。
